# 🔌 ARM Cortex-M — Embedded Systems

An embedded systems project exploring ARM Cortex-M microcontrollers using the **STM32F103C8T6**, with hardware configuration through STM32CubeMX and task simulation in Proteus 8.

## 📌 Overview

The ARM Cortex-M family is designed for low-cost, energy-efficient microcontroller applications. This project provides practical experience with the STM32 platform and embedded development workflows, including microcontroller configuration, initialization code generation, and simulation.

## ⚙️ Hardware & Development Environment

- **Microcontroller:** STM32F103C8T6
- **Processor Architecture:** ARM Cortex-M
- **Configuration & Code Generation:** STM32CubeMX
- **Simulation:** Proteus 8
- **Development Topics:** ARM assembly, ARMv7, and embedded programming
